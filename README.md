# 90s FBI Secure Terminal

Green-on-black loading screen → Windows 98 desktop (with “I Want to Believe” wallpaper) → open window containing your assignment.

## What you see

1. Black screen with bright green terminal text
2. Typewriter login sequence identifying Agent Scully (subtle, professional tone)
3. Fades into a Windows 98 desktop using the classic poster as wallpaper
4. A 90s-style window already open with Scully’s personal log (your essay goes here)
5. Heavy CRT scanlines + flicker throughout

## Files to upload to GitHub

- `index.html`
- `style.css`
- `boot.js`
- `wallpaper.png`
- `README.md` (optional)

## Put your essay in

Open `index.html` and find this comment:

```
<!-- ========== REPLACE EVERYTHING BELOW WITH YOUR 1500-WORD ESSAY ========== -->
```

Replace the placeholder paragraphs with your full essay.

## Publish on GitHub Pages

1. Create a repo (best name: `yourusername.github.io`)
2. Upload all the files above
3. Settings → Pages → Deploy from `main` branch
4. Done
